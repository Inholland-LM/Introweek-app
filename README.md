# Introweek-app

Mobiele begeleider voor de Introweek LM 2026.

## Uitgangspunten

- mobile-first en toegankelijk;
- vaste programma-inhoud wordt lokaal meegeleverd;
- live gegevens blijven klein en doelgericht;
- geen agressieve polling;
- geschikt om als Progressive Web App te installeren.

## Lokaal starten

```bash
npm install
npm run dev
```

## Productiebuild

```bash
npm run build
```

De eerste versie gebruikt voorbeeldgegevens voor LM1A (Australië). Database- en Excel-importfunctionaliteit worden in aparte, controleerbare stappen toegevoegd.
